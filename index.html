Hermes Personal

A personal workflow that keeps a Google Sheet as a redundant copy of a local SQLite database.

A straightforward connection

The Hermes Personal project uses owner-authorized Google Sheets access for a private spreadsheet workflow. Deterministic writes run on a schedule to copy data from a locally running SQLite database to the owner's Google Sheet.

This workflow is for the owner's personal use. It is not offered as a public service and does not accept public registrations.

Owner-authorized access

Google account access depends on the permissions the owner grants through Google's authorization process. The owner manages the local source database and the spreadsheet copy.

Read the privacy policy for this workflow's data handling and access controls.

An informational website only

These pages describe the Google Sheets workflow. They do not run the integration, offer a sign-in flow, or contain database contents, spreadsheet contents, or credentials.
