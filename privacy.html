Privacy policy

For the private, owner-operated Google Sheets workflow within the Hermes Personal project.

What this policy covers

This policy covers a single-owner workflow that maintains a Google Sheet as a redundant copy of a locally running SQLite database, using deterministic writes on a schedule. It does not describe other Hermes functionality or integrations.

The workflow is for personal use, not a public service. There are no public registrations.

Data access and use

The workflow uses Google Sheets access authorized by the owner to read and write spreadsheet data for this copying process. Requested permissions are presented during Google's authorization process; access depends on the permissions the owner grants.

The source database runs locally. Scheduled writes send data to the owner's Google Sheet, where the redundant copy is stored. This workflow does not send spreadsheet data to an AI or model provider for processing.

Retention and deletion

The owner manages retention of the local SQLite source and the Google Sheets copy. No fixed automatic deletion period is specified for this personal workflow.

To stop scheduled copying, the owner can disable the workflow. To remove retained data, the owner must manage deletion separately in the local database and in Google Sheets, including any copies or backups the owner has made.

Revoking Google access

The owner can revoke access through their Google Account's linked-app settings. Revoking access stops future access through that permission grant; it does not automatically delete data already stored locally or in the Google Sheet. See Google's guidance on linked-app access.

This informational website

These static pages contain no database contents, spreadsheet contents, credentials, or application backend. They do not provide a sign-in flow or collect information through forms. The site code includes no analytics, advertising, tracking scripts, or cookies.

When these pages are served by GitHub Pages, GitHub records and retains visitors' IP addresses for security, including visits made without signing in to GitHub. See GitHub Pages data collection and the GitHub General Privacy Statement.

GitHub Pages hosts this informational content, not the local database or the Google Sheets integration.

Contact

For questions about this integration, use the support contact shown on its Google authorization consent screen.

Changes to this policy

If this workflow's data practices change, this policy will be updated to describe them. The effective date appears at the top of this page.
